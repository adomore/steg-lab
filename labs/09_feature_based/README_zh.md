# Lab 09 -- 基于特征的检测，以及一个必须先训练的检测器

| | |
|---|---|
| 嵌入域 | spatial |
| 算法族 | embedder-agnostic |
| 检测器 | `spam686_fld_ensemble` |
| 对 LSB matching 在 1.0 bpp 的 P_E | 0.140 |
| 来源失配时的 P_E | 0.487（随机水平） |
| 证据上限 | E3 |

## 这个模块关掉了什么

Lab 08 没有发布任何检测器：RS 分析、Weighted Stego 与卡方对 LSB matching 全都落在
距随机水平 0.086 以内。这里是它改变的地方。

SPAM 不再对嵌入器的伪痕建模，而是对**载体**建模——具体说是相邻像素差之间的二阶依赖
关系。任何嵌入都会扰动这些依赖，无论它是否尊重值对结构。

| 检测器 | 对 LSB matching 在 1.0 bpp 的 P_E |
|---|---|
| RS analysis | 0.473 |
| Weighted Stego | 0.450 |
| SPAM686 + FLD ensemble | **0.140** |

## 它按所声称的理由生效的证据

如果这个分类器抓住的是某种 replacement 专有的东西，它在两种嵌入器上的得分会差很多。
并没有：

| 嵌入器 | 1.0 bpp 的 P_E |
|---|---|
| LSB matching | 0.140 |
| LSB replacement | 0.120 |

差距 0.02。这个方法之所以与嵌入器无关，是因为它对载体建模——这个论断现在被量出来了。

## 为什么 `detect` 拒绝在未训练时运行

之前每一个模块暴露的检测器都是一个函数。这一个不能是，而 API 直说了这一点：
`detect` 需要一个 `classifier`，没有就返回 E0。

特征集分类器没有固定的判决规则，它只有**针对某个来源**的判决规则。Gate G5 判据 D
量出了无视这一点的代价：

| | P_E |
|---|---|
| 在相同图像族上训练与测试 | 0.140 |
| 在 texture/photo_like 上训练，在 gradient/flat 上测试 | 0.487 |

这不是优雅退化，这是分类器停止工作。一个随仓库发布的预训练检测器，是按别人的来源
校准的，它在你的检材上产出的数字毫无意义。

## 绝对性能，如实说

0.5 bpp 时 P_E = 0.297，很差。已发表的 SPAM686 在 BOSSbase 上的结果在同样载荷下要好
一个数量级，那是用一万张真实相机图片而不是 150 张合成图训练出来的。

**相对**结果——特征集能检测到结构估计量检测不到的东西——才是可迁移的。绝对数字不可
迁移，把它们引用到本语料之外属于误用。

## 复现

```bash
python3 gates/g5_feature_sets.py --n 300
python3 -m pytest tests/test_labs_c.py -q
```

## 它教什么

从估计量走到分类器，买到的是普适性，付出的是可移植性。证据阶梯关于同源基线所说的
一切，在这里从建议变成了承重结构。
