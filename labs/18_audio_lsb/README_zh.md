# Lab 18 -- 音频 LSB：位深击败统计检测，而静音不在乎

| | |
|---|---|
| 嵌入域 | audio |
| 算法族 | lsb-replacement |
| 检测器 | `audio_silence_lsb`（结构化）、`audio_weighted_stego`（统计） |
| 实测误报率 | 8 位与 16 位均 0/16 |
| 证据上限 | E4 —— 顺序路径，载荷复原 16/16 |

## 位深就是统计检测的全部故事

8 位采样跨 256 级，所以翻转最低位把它移动了满量程的 1/256。16 位采样跨 65,536 级，同样一次
翻转只移动 1/65,536——相对载体安静了四十八分贝。

用两邻居预测器的 Weighted Stego，同样相对载荷下干净对隐写：

| 位深 | 干净 | 隐写 | 比值 |
|---|---|---|---|
| 8 位 | 0.0130 | 0.2689 | **20.7x** |
| 16 位 | 1.1822 | 1.3253 | **1.1x** |

估计量没有变，唯一的差别是载体的精度。到 16 位，检测器赖以工作的那个残差被埋掉了——而这不是
调参问题，这是算术。**任何提高载体精度的做法，都给嵌入方买到同样的保护。**

## 静音不在乎位深

音频有一种图像没有的结构：数字静音段，那里每个采样都精确等于静音电平。LSB replacement 把它们
变成「该电平」与「该电平加一」的交替流。

有两个格式细节决定这项检查成败，而且都属于会**悄悄失效**的那类：

**静音不总是零。** 8 位 WAV 是**无符号**的、中点为 128；更宽的都是有符号、中点为 0。在 8 位
片段里找零，找到的是波形最负的偏移，静音则完全被漏掉。

**要找的是「近静音」而不是「静音」。** 搜索条件是与电平相差不超过 1，而不是等于它——因为把那些
「一」放进去的正是嵌入本身。找精确相等，会让被嵌入的段对本该抓住它的检查隐形。

## 那个消掉误报的判别式

第一版把任何「含非电平采样的静音段」都标记出来，在 8 位片段上给出 2/16 误报——在那个量化分辨率
下，一段真正安静的乐句仅凭幅度与静音无法区分。

LSB replacement 只能产生该电平或它**上方**一级。而真正安静的段会在电平两侧穿越，因此也包含
「电平减一」。要求偏移是**单侧**的之后，误报降到 **8 位与 16 位均 0/16**。

## 它能抓到什么、抓不到什么

| | 8 位 | 16 位 |
|---|---|---|
| 干净误报 | 0/16 | 0/16 |
| 在含静音的片段中检出 | 4/12 | 7/12 |
| 载荷逐字节复原 | 16/16 | 16/16 |

漏掉的那些不是阈值问题。1200 字节的载荷占据 22,050 采样片段的前 9,600 个，所以更靠后的静音段
根本没被碰过。在单个片段上直接量：200 字节给 E0，1,200 字节才有发现。**结构检查只在载荷抵达
静音处时才会响**，而完全没有静音的片段对它不可见——在无静音载体上 0/8，这是对的。

这正是结构检测器诚实的形状：适用处决定性、不适用处失明，中间从不猜测。

## 解析器

`steganalysis.wav` 走 RIFF 块流、不向任何解码器提问，在 6 个片段上与 Python 的 `wave` 模块在
声道数、采样率、帧数以及每一个采样上完全一致。RIFF 泄漏的位置与 PNG、JPEG 是同样三处——声明的
大小之后还有字节、没人读的块、以及比后续内容更短的 `data` 块——所以 A 组的习惯原样迁移过来。

## 复现

```bash
python3 -m pytest tests/test_labs_f.py -q
```

## 它教什么

同一个载体上的两个检测器，而载体的精度彻底击败了其中一个、对另一个毫无影响。当一份报告说某种
手法「未被检出」时，该问的是用了哪个检测器，以及这个载体是不是它能工作的那种。
