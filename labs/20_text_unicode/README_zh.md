# Lab 20 -- 文本载体：难点在误报

| | |
|---|---|
| 嵌入域 | text |
| 算法族 | zero-width、variation-selector、trailing-whitespace |
| 检测器 | `text_zero_width`、`text_variation_selectors`、`text_trailing_whitespace` |
| 实测误报率 | 合法多语种语料上 0/8 |
| 证据上限 | E4 —— 三条通道都不需要密钥 |

## 文本与之前每一种载体的根本差别

PNG、JPEG、WAV、调色板里的藏身处，都是**没有任何正当用途需要**的字节。没人注册过的块。没有解码器
会读的段。精确等于零的静音。找到它们是工作量问题；一旦找到，没什么可争的。

**而用来在文本里藏东西的字符，是在干真活的。** ZERO WIDTH NON-JOINER 分隔波斯语和乌尔都语的
词素。ZERO WIDTH JOINER 构造 emoji 序列和天城文合体字。VARIATION SELECTOR-16 正是让 emoji 渲染成
emoji 而不是符号的那个东西。

一个把所有不可见字符都标记出来的检测器，会报告有史以来每一份多语种文档。在真正要紧的语料上，
那就是 100% 的误报率。

所以这个模块的内容不是「找出不可见字符」，而是：**在它们无处不在且大多无辜的前提下，什么区分了
「在承载」与「在书写」？**

## 三个上下文信号

**连续段。** 正字法在两个字母之间放**一个**连接符。载荷比特是连续到达的，所以长度 ≥3 的连续段在
任何文字系统里都没有读法。

**脚本上下文。** 两个 ASCII 字母之间的 ZWNJ 没有任何正字法职能，因为没有用 ASCII 书写的文字需要它。
这是能扛住谨慎对手的那个信号——见下。

**选择符区段。** VS15 与 VS16 是表现形式选择符，无处不在。VS17 往上是为表意文字变体序列（IVS）
存在的，跟在非 CJK 基字后面毫无意义——而且它们**每个携带整整一个字节**，这让那条通道比零宽字母表
密八倍。

## 谨慎的对手，以及是哪个信号抓住它

笨拙的嵌入器把比特写成一整块：104 个零宽字符连成一段，连续段信号立刻发现，而且没有内行会这么干。

谨慎的那个把单个比特分散到字母之间，于是最长连续段是 1、连续段信号什么也报不出来：

| 对手 | 最长连续段 | 超阈值段数 | 位于 ASCII 字母之间的段数 | 判定 |
|---|---|---|---|---|
| 连续块 | 104 | 1 | 0 | 检出 |
| **分散** | **1** | **0** | **48** | **检出** |

两个互相独立的信号，而击败其中一个的对手正好撞进另一个。这就是「要两个而不是把一个调好」的论据。

## 合法语料：0/8

| 文本 | 零宽字符数 | 判定 |
|---|---|---|
| 英文散文 | 0 | E0 |
| 带 ZWNJ 的波斯语 | 3 | E0 |
| emoji ZWJ 序列加 VS16 | 2 | E0 |
| 带 ZWNJ 与 ZWJ 的天城文 | 2 | E0 |
| 带表意变体序列的 CJK | 0 | E0 |
| 波斯语第二个样本 | 2 | E0 |
| 带变音符的拉丁文 | 0 | E0 |
| 前置 BOM 的 URL | 1 | E0 |

这里每一条都含有正在履行职能的不可见字符，而没有一条被报出来。

## 尾部空白需要同样的处理

统计「以空白结尾的行数」会把普通文档标记出来：编辑器到处留下多余空格，而 Markdown 的硬换行约定
就是两个尾部**空格**。

区分「编码」与「意外」的有两件事。**制表符**——散文基本不会用它结束一行，而空格/制表符字母表
每一个 1 比特都需要它。以及**连续性**——载荷占据连续行的一个前缀，因为那就是它被写入的顺序。

| 文本 | 尾部制表符 | 最长连续行 | 判定 |
|---|---|---|---|
| SNOW 式载荷 | 22 | 32 | 检出 |
| Markdown 硬换行 | 0 | 1 | E0 |
| 编辑器残留 | 0 | 1 | E0 |

## 三条通道都能到 E4

它们都不需要密钥。零宽字母表是固定的，选择符区段直接映射到字节值，空白编码按顺序读行尾。确认了
存在，载荷就跟着出来——与 Lab 13 和 Lab 10 到达 E4 的属性相同，理由也相同。

## 复现

```bash
python3 -m pytest tests/test_labs_g.py -q
```

## 它教什么

之前每一个模块都可以把误报基线当作**来源**的属性。在这里它是**语言**的属性：一个在英文散文上校准、
拿去用在波斯语上的检测器，不是「稍微有点偏」，而是没用。证据阶梯对同源基线的要求，在这个域里读作
「同一文字系统」。
