# 事故叙事

真实事件，以叙事形式写就，并附检测归因表：藏了什么、藏在什么载体里、如何被发现、
以及哪一项检查本可以更早发现它。

第一篇：[stegomalware](stegomalware_zh.md)——Duqu、Zeus/Zbot、Gatak/Stegoloader 与 Worok，
按载体而非按时间排列，每条都给出本可以发现它的检查以及教这项检查的模块。它同时列出本仓库
不覆盖的载体，因为覆盖缺失不等于风险缺失。

预期格式沿用姊妹审计实验室的 `docs/incidents/`：叙事段、时间线，以及一张把每个检测
信号映射到教授它的模块的表。
