# Case narratives

Real incidents, written as narratives with a detection-attribution table:
what was hidden, in what carrier, how it was found, and which check would
have found it earlier.

First entry: [stegomalware](stegomalware.md) -- Duqu, Zeus/Zbot,
Gatak/Stegoloader and Worok, arranged by carrier rather than by date, with the
check that would have found each and the module that teaches it. It also lists
the carriers this repository does not cover, because absent coverage is not
absent risk.

The intended format follows `docs/incidents/` in the sibling audit lab: a
narrative section, a timeline, and a table mapping each detection signal to
the lab module that teaches it.
