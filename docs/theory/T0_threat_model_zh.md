# T0 -- 问题定义与威胁模型

> Gate：**G0** -- `python3 gates/g0_wardens.py` -- 已通过

## 0.1 囚徒问题

Simmons 1983 年的表述至今仍是正确的框架。Alice 与 Bob 分别关押，可以互通消息，
但每条消息都要经过一名看守，一旦她怀疑存在隐藏的对话，就会切断信道。

关键之处在于：对手是由**她被允许对信道做什么**来定义的，而不是由她有多聪明来定义。
这个区分统摄了后面的一切，因为能击败某一类看守的技术，对另一类可能完全无关。

| 看守 | 能力 | 对发送方的要求 |
|---|---|---|
| 被动 | 只观察，原样转发 | 必须不可检测 |
| 主动 | 无恶意地改动，不知道是否存在载荷 | 必须鲁棒 |
| 恶意 | 蓄意改动，可替换内容 | 必须可认证 |

## 0.2 三条需要分清的边界

**隐写术**隐藏消息的存在。**密码学**隐藏消息的内容。**数字水印**嵌入的是一个所有权
标记，目标是在攻击下存活而非不被注意。**隐蔽信道**通过一个本不用于承载信息的系统
资源传递信息。

实践后果是：隐写信道**不提供**保密性，也**不提供**完整性。如果载荷本身重要，它必须
自带加密与认证。0.5 节量化了不这么做的后果。

## 0.3 「安全」的形式定义

Cachin 的模型把检测看作在载体分布 `P_C` 与隐写分布 `P_S` 之间做假设检验。当两者
的相对熵有界时，系统是 **ε-安全**的：

```
D(P_C || P_S) <= epsilon
```

完美安全是 `epsilon = 0`：两个分布完全相同，于是任何检验——无论计算能力多强——都
不优于掷硬币。Hopper、Langford 与 von Ahn 给出了复杂性理论上的对应版本，其安全性
针对计算受限的对手，并依赖于载体来源存在一个采样谕示机。

比形式化更重要的是它的实践读法。嵌入方对载体所做的一切，都是**对载体来源自身分布
的偏离**，而每一个检测器都是对这个偏离的估计量。这也是为什么本领域最难的问题不是
检测，而是搞清楚载体分布究竟是什么——这个主题会在 T4 以「载体来源失配」的形式回来。

## 0.4 三方权衡

容量、不可感知性、鲁棒性无法同时最大化：

- 在载体大小固定时提高**容量**，会加大对 `P_C` 的偏离，从而降低不可感知性
- 提高**鲁棒性**需要冗余，而冗余消耗容量
- 把**不可感知性**推到极致，会逼得嵌入量小到信道失去意义

真实系统都是在挑角落。steghide 选了不可感知性与容量，彻底放弃鲁棒性——下面的 G0
量的正是这一点。

## 0.5 Gate G0：把三种看守量出来

「三类看守在操作层面确有区别」这个主张没有被当成断言放过。`gates/g0_wardens.py`
为每一类各造了一个可复现的实例。

### 判据 A -- 被动看守

12 次试验，顺序 LSB 载荷，经真实编码器做 PNG 往返。**最大误码率 0.0。** 载荷逐字节
抵达，因此看守唯一可用的动作就是检测。这正是被动场景成为统计隐写分析主战场的原因。

### 判据 B1 -- 主动看守对 LSB

12 次试验，JPEG 质量 90 重压缩，且不知道是否存在载荷。

| 统计量 | 数值 |
|---|---|
| 中位误码率 | 0.498 |
| 最小误码率 | 0.473 |
| 最大误码率 | 0.510 |
| 判据 | > 0.45 |

误码率 0.5 意味着恢复出的比特不携带任何信息。一次有损重压缩——每个即时通讯软件都
会自动做的那种——就彻底摧毁了这条信道。

### 判据 B2 -- 主动看守对 steghide

12 次试验。先跑对照组（无看守）提取成功，否则这个实验什么也证明不了。然后看守以
质量 90 解码再编码。

**提取失败 12/12，载荷存活 0。**

### 值得注意的不对称

B1 与 B2 都报告了「全损」，但这不是同一个结果。LSB 是**优雅降级**：比特还在，只是
大约一半是错的，原则上纠错码还能捞回一部分。steghide 是**灾难性失效**：它没有任何
纠错，一个系数被改动就足以让整个提取失败，接收方拿到的是「什么也没有」而不是
「一个损坏的东西」。

设计层面的教训：鲁棒性不是靠挑一个好的嵌入域就能获得的属性，它必须被工程化，而
几乎没有通用隐写工具去工程化它。

### 判据 C -- 恶意看守

12 次试验。看守知道信道约定但不知道消息内容，它用自己的载荷覆写原载荷后转发。

**伪造被接受 12/12。**

接收方提取出被替换的消息，且无从察觉。这是 0.2 节的具体演示：隐写隐藏的是存在性，
不是完整性。保密性与认证必须来自载荷自身的密码学，且必须在嵌入**之前**施加。

## 0.6 这对分析员意味着什么

把上表从检测侧而非嵌入侧读一遍：

1. 面对**被动**信道，结构检测与统计检测就是全部战场，A 组模块正是从这里开始。
2. 面对**主动**信道，「没有载荷」什么也证明不了。一张被重压缩的图片可能曾经携带过
   一个如今已不存在的载荷。报告必须写清楚被检验的到底是哪一种。
3. **恶意**看守也是分析员拥有的一种能力。摧毁一条可疑信道成本很低，在行动层面往往
   是正确答案，但它不是证据，而且会毁掉检材。动手之前先想清楚你在做哪一件事。
