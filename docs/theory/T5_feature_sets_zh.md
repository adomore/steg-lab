# T5 -- 特征集与集成分类

> Gate：**G5** -- `python3 gates/g5_feature_sets.py` -- 已通过

## 5.1 估计量为什么走到了尽头

T4 以一句承认收尾：RS 分析与 Weighted Stego 能检测 LSB replacement，对 LSB matching
则等同随机——三个发布的检测器在每一档载荷上都落在距随机水平 0.086 以内。

这不是那些估计量的缺陷。它们各自对一种特定结构建模——replacement 留下的奇偶不对称
——而 matching 不制造这种结构。再怎么调参也变不出一个根本不存在的结构。

出路是不再对**伪痕**建模，转而对**载体**建模。

## 5.2 SPAM

SPAM 看的是相邻像素之间的局部依赖关系，而不是像素值本身。取八个方向上相邻像素的差，
把它们截断到 [-3, 3] 区间（因为尾部稀疏），再把每条差分序列建模为二阶马尔可夫链。
这样每个方向得到 7^3 = 343 个转移概率；把水平与垂直方向平均成一组、两条对角线平均成
另一组，就得到标准的 **SPAM686**。

有两个实现细节承担了真实的重量：

**条件归一化。** 每个 `(u, v)` 条件状态是各自归一化的，不是全局归一化。SPAM 是一个
条件模型；跨全部状态归一化，强状态会把弱状态抹平，信号大半就没了。

**方向平均是一个假设，不是一个捷径。** 它编码了「载体统计是方向对称的」这一论断。
这在不丢弃载体本应含有的任何东西的前提下把维度减半——而由于它是一个关于载体的论断，
它就又多了一样在你没刻画过的来源上可能失效的东西。

## 5.3 为什么要用弱学习器的集成

686 个特征配几百张训练图，是一个条件极差的问题。在全部特征上做单个 Fisher 判别会
过拟合，而且它的类内协方差估计接近奇异。

FLD 集成绕开而不是解决这个问题：每个基学习器拿到约 200 个特征的随机子空间和训练集的
自助样本，算出闭式的 Fisher 方向，挑一个让自己训练误差最小的阈值，然后投票。随机
子空间让每个子问题保持良态，装袋让学习器之间去相关。

它成为标准的隐写分析分类器，很大程度上是因为它**快到可以按来源重新训练**，而按来源
重新训练，最后被证明是诚实使用这一整套东西的唯一方式。

## 5.4 P_E，以及它掩盖了什么

这个领域的标准指标是等先验下的最小平均判决错误：

    P_E = min over thresholds of (P_FA + P_MD) / 2

它不是准确率。它给虚警与漏检同等权重，这对实验室里比较方法是合理的默认，对几乎任何
真实案件都是错的默认——那里两种错误的代价差得很远。任何实用阈值都必须带着这些代价
重新从 ROC 上挑。

## 5.5 这道 gate 量出了什么

**T4 的缺口关上了。** 对 LSB matching 在 1.0 bpp：

| 检测器 | P_E |
|---|---|
| RS analysis | 0.473 |
| Weighted Stego | 0.450 |
| SPAM686 + FLD ensemble | **0.140** |

**而且它是按所声称的理由关上的。** 如果分类器抓住的是某种 replacement 专有的东西，
它在两种嵌入器上的得分会差很多：

| 嵌入器 | 1.0 bpp 的 P_E |
|---|---|
| LSB matching | 0.140 |
| LSB replacement | 0.120 |

差距 0.02。这个方法与嵌入器无关，是因为它对载体建模。那是论断，这是测量。

## 5.6 载体来源失配，现在躲不掉了

T4 是偶然撞见它的——基线取自错误的图像族，把误报率从 0% 推到了 25%。在这里它是结构
性的。

在一个图像族上训练分类器，在另一个族上测试：

| | P_E |
|---|---|
| 在 texture/photo_like 上训练与测试 | 0.140 |
| 在 texture/photo_like 上训练，在 gradient/flat 上测试 | **0.487** |

0.487 就是随机。这不是优雅退化，这是分类器彻底停止工作。

其操作后果，就是 Lab 09 的 `detect` 拒绝在没有 classifier 参数时运行。特征集检测器
没有固定的判决规则——它只有**针对某个来源**的判决规则。一个随仓库发布的预训练分类器
是按别人的相机校准的，它在你的检材上产出的数字毫无意义。这个 API 被造成让人无法忘记
这件事，而不只是把它写进文档。

这也是证据阶梯坚持要**同源**基线不再只是一种风格偏好的地方。在 E3 及以上，阶梯要求
一个来自同一来源的实测误报率；没有它，你拿到的就是上面那个数。

## 5.7 同一道 gate 跑在真实照片上

BOSSbase 1.01，200 对训练、200 对测试，全部来自同一台相机（canon_eos_7d），所以训练集
是真正的同源。

| 量 | 合成 | 真实 |
|---|---|---|
| 对 LSB matching 在 1.0 bpp 的 P_E | 0.140 | **0.125** |
| 对 LSB matching 在 0.5 bpp 的 P_E | 0.297 | **0.215** |
| 同一任务上最好的结构检测器 | 0.450 | 0.405 |
| 相对结构检测器的优势 | 0.31 | 0.28 |

T4 打开的那个缺口在真实数据上依然是关上的，相对结构估计量的优势也存活了下来。

判据 C 产出了更有意思的数字。对 LSB replacement，P_E 是 **0.030**；对 matching 是
0.125。replacement 留下更多结构，所以它当然更容易——但这条判据原本要求两者相差在 0.10
以内，而 0.095 距离失败只有千分之一。要是 SPAM 对 replacement **更强**一些，它就会直接
失败，这很荒谬。被检验的论断是「两种嵌入器都不是不可见的」，所以判据现在要求两个 P_E
都在 0.25 以下，并把差距单独报出来。

## 5.8 载体来源失配真正的代价，一分为二

判据 D 在第一次接触真实数据时就失败了，而这次失败正是有用的部分。

在 canon_eos_7d 上训练、在 nikon_d70 上测试，P_E 从 0.125 变成 **0.160**——退化 0.035，
而要求是 0.05。在合成图像族上，同一条判据量到的是从 0.140 崩到 0.487。

阈值没有被放松。差异的原因是结构性的：**BOSSbase 里每一张图都经过了同一套 RAW 开发
脚本和同一次缩放。** 在那上面做跨相机比较，隔离出来的只有传感器，其余一切都被固定住了。
而合成那次比较是纹理图像对平坦与渐变图像——那是一次**内容**位移，比任何传感器差异都
剧烈得多，从来就不是这条判据的公平标定。

于是判据一分为二：

**D1，传感器位移。** 在一台相机上训练，在其余几台上测试。多数配对必须出现正向退化。
按构造它就是温和的，而这是关于数据集的事实，不是一个弱结果。

**D2，处理链位移。** 同样的图像、同样的相机，只做一次重采样——面积平均降到二分之一，
再双线性升回去。必须退化至少 0.05。在合成载体上，仅这一步就把 P_E 从 0.163 推到
**0.500**，彻底崩溃。

操作层面的读法：换相机代价是几个点；把检材过一次缩放，代价是全部。而实际案件几乎总是
后者，因为检材抵达时已经被缩放、重编码、平台转码过了。一个在原始未处理图上训练出来的
分类器，在它面前站不住。

## 5.9 绝对性能，如实说

0.5 bpp 时 P_E = 0.297，很差。已发表的 SPAM686 在 BOSSbase 上的结果在同样载荷下要好
一个数量级，那是用一万张真实相机图片而不是 150 张合成图训练出来的。

**相对**结果——特征集能检测到结构估计量检测不到的东西，而且与嵌入器无关——才是可迁移
的。绝对数字不可迁移，把它们引用到本语料之外属于误用。缺口 G-4 在真实语料到位之前
保持开启。

## 5.10 SPAM 之后是什么

SRM（Spatial Rich Models）把这个想法一般化：用几十个残差滤波器代替一个差分算子，用
几万个特征代替 686 个，上面接同样的集成分类器。maxSRMd2 再按「嵌入最可能发生在哪里」
的估计给残差加权。JPEG 域里的对应物是 DCTR 与 GFR。

前进方向是一致的——更丰富的载体模型，同样的分类器——一直走到 T6 用学出来的残差替换
手工设计的残差为止。
