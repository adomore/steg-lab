# T6 -- 深度学习隐写分析

> Gate：**G6** -- `python3 gates/g6_deep_learning.py` -- 已通过

## 6.1 把设计出来的残差换成学出来的

T5 以手工设计的残差收尾：一个差分算子、686 个特征、上面接一个集成分类器。T6 把「设计」这一步
换成「训练」。这次替换之后什么东西还站得住，才是有意思的问题，而回答它的办法是把网络造出来、
然后一件件拆掉零件。

`steganalysis.cnn` 是约 8,200 个参数的 numpy——im2col 卷积、batch normalisation、手写反向
传播、带动量的 SGD。没有框架，没有 GPU。反向传播在 gate G6 里对着中心差分校验，而不是靠信任。

## 6.2 三个架构论断

**第一层是固定的高通滤波器，不训练。** 这是 Xu-Net 的核心贡献。在原始像素上训练的网络必须先学会
压制图像内容，而图像内容比隐写信号大若干个数量级。把 KV 核直接交给它，等于让它从残差已经在的地方
起步。

**第一个卷积之后的激活是 |x|。** 嵌入是对称的：+1 与 −1 等概率，所以残差的符号对「是否存在载荷」
不提供任何信息。

**池化用平均，绝不用最大。** 隐写信号幅度低且铺满整个载体。最大池化保留每个窗口里响应最强的那个，
那恰好是保留图像内容、丢掉载荷。

## 6.3 这道 gate 量到了什么

在 BOSSbase 上，300 张载体中心裁剪到 64px，LSB replacement 1.0 bpp，150 对训练、150 对测试：

| 判据 | 合成 64px | **BOSSbase 128px** |
|---|---|---|
| 梯度对中心差分 | 7e-08 | 4e-06 |
| 优化可用（记住 32 个样本） | 0.786 → 0.184 | 0.800 → 0.253 |
| CNN 测试 P_E | 0.419 | **0.163** |
| **移除固定高通层** | 0.488（代价 0.069） | **0.493（代价 0.330）** |
| ABS 换成 ReLU | 0.413 | 0.170 |
| SPAM686 + 集成，同一划分 | 0.425 | **0.120** |

**高通那条论断被确认了，而且在真实载体上一点都不细微。** 移除固定首层把网络从 P_E 0.163 推到
0.493——从一个能用的检测器变成**随机**，而架构其余部分完全相同。Xu-Net 的贡献不是一项改良；
没有它，这个网络根本不工作。

**ABS 那条复现了——在层放对位置之后。** ABS 量到 0.163、ReLU 0.170，领先 0.0067；但这个尺度下
太小、撑不起一条判据，所以 gate 报告它而不评分。6.5 节讲这个数字是怎么来的，因为它曾经有两轮
是相反的符号。

**而手工设计的特征仍然赢。** SPAM686 加集成分类器在同样载体、同样划分上达到 P_E 0.120，CNN 是
0.163，而前者一步梯度都没走。在 150 对 128px 裁剪上这是符合预期的顺序，值得直说：学出来的残差
得靠数据挣饭吃，而这里给它的数据不够。

## 6.4 激活该放在哪里

Xu-Net 规定的是 卷积 → ABS → 归一化。本章有两轮写成了 卷积 → 归一化 → ABS，而后果值得占这些篇幅。

BN 把输出中心化到零。对零中心分布取 |x| 得到均值约 +0.8 的半正态，而归一化已经用掉了，在下一个
卷积之前没有任何东西重新中心化它。在层序错误的情况下、BOSSbase 128px 上实测：ABS 0.2333 对
ReLU 0.1367，ReLU 领先 0.0966——是 64px 时差距的四倍，而**差距随尺度增大**通常就宣告「检验力不足」
这条辩护结束了。

梯度检查独立地裁决了它。激活放在归一化之后，最大相对误差 5e-02；放在之前，5e-09。原因是精确的：
|x| 在零点有折点，而归一化后的激活恰好集中在那里——旧的排列在要紧的地方**不可导**。

改正顺序翻转了 ABS 效应的符号——并且改善了本章其余每一个数字。网络从 P_E 0.2333 变成 0.1633，
移除高通层的实测代价从 0.26 涨到 0.33。**一个放错位置的层，一直在压低那些看起来都很合理的结果。**

可迁移的部分不是这个 bug，而是：**一个与已发表工作相悖的结果，作为线索的价值大于作为结论的价值。**
「ABS 没用」看着像个可以发表的结论、是错的，而且会把造成它的缺陷埋掉。起决定作用的是坚持要一个
**机制**——「ABS 没用」不可证伪，「ABS 放在归一化之后会摧毁中心化」可以，而检验它只花了一个实验。

## 6.5 两次从外面看起来一模一样的失败

它们比上面那些结果更值钱。

**网络根本学不动。** 每个数字都回到随机水平，训练 loss 卡在 ln(2) = 0.6931。显而易见的读法是
「任务没有信号」。那是错的：激活在层间坍塌了——KV 在缩放后输入上的响应很小，He 初始化在每个卷积
又缩一次，到全局平均池化时已经没有可用梯度能回到早期层。batch normalisation 修好了它。这就是为什么
这一族里每个已发表的架构都在层间放归一化，而它值得作为「关于优化的事实」来知道，而不是架构图上的
一行。

**修了之后它还是学不动。** 32 个样本用批量 32，就是一个 epoch 一步优化，于是 60 个 epoch 就是 60 步。
改成批量 8 加更高的学习率，同一个网络在 600 步里记住了同一批数据。

**过拟合检查**能把「优化不了」和「没东西可找」分开。这两者表现完全一样——全在随机水平——而需要的
应对完全相反。它现在是判据 B，排在所有依赖它的结果之前。

## 6.6 把这笔交换直说

手工设计的残差不需要训练，上限就是被设计进去的那些东西。学出来的残差需要数据和时间，但没有那个上限。
在这个语料、这个载体尺寸、这点算力下，设计出来的残差并不落后——这是「一个 numpy 网络跑 160 张 64×64
合成图」的诚实总结，而它对方法本身什么也没说。

本章可迁移的是那个**消融**，不是分数：在其余完全相同的网络上，固定高通层挣到了它的位置，而且是量出来的。

## 6.7 之后是什么

SRNet 把网络做得足够深，让它自己学出残差，从而不再需要固定首层。SCA 变体把选择信道知识——「嵌入
更可能发生在哪里」的估计——喂给网络，那正是 T3 的代价函数从另一头走来。两者需要的规模都超出本章。
